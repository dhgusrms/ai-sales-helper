# AI 온라인 판매 도우미 (1차 버전)

예비창업자와 소상공인이 상품 정보를 입력하면 AI가 상품을 분석하고, 예상 수익과 판매 가능성을 알려 주는 웹사이트입니다.

## 실행 방법

1. 이 폴더의 `index.html`을 더블클릭해 Chrome·Safari·Edge 등 브라우저로 엽니다. 별도 설치는 필요 없습니다.
2. 오른쪽 위 **AI 설정**에서 사용할 AI를 고릅니다. Claude는 Anthropic API 키를 입력합니다. 키는 https://console.anthropic.com/settings/keys 에서 발급하며, 사용량만큼 요금이 부과됩니다.
3. 상품 정보를 입력하고 **AI 분석 시작**을 누릅니다.

API 키가 없어도 수익성 분석(순이익, 마진율, 권장 판매가, 가격별 비교)은 바로 확인할 수 있습니다.

## Qwen 테스트 모드 (임시, 무료)

API 키 없이 내 컴퓨터에서 작은 Qwen 모델로 분석을 시험해 볼 수 있습니다. 상품 사진과 PDF 자료는 반영되지 않고, 분석 품질은 Claude보다 낮을 수 있습니다.

1. https://ollama.com/download 에서 Ollama(macOS)를 내려받아 설치하고 실행합니다.
2. 터미널에서 모델을 받습니다 (약 5.2GB):
   ```bash
   ollama pull qwen3:8b
   ```
3. 브라우저에서 연 파일(index.html)이 Ollama에 접속할 수 있도록 허용한 뒤, 메뉴 막대의 Ollama 아이콘에서 Quit Ollama를 눌러 종료하고 다시 실행합니다:
   ```bash
   launchctl setenv OLLAMA_ORIGINS "*"
   ```
   이 설정은 컴퓨터를 재시동하면 사라집니다. 테스트가 끝난 뒤 바로 지우려면 `launchctl unsetenv OLLAMA_ORIGINS`를 실행하고 Ollama를 다시 실행하세요.
4. 웹사이트 오른쪽 위 **AI 설정**에서 "Qwen 테스트 모드"를 선택하고 저장합니다.

기본 모델은 `qwen3:8b`입니다 (분석 1회 약 2분). 더 빠르게 시험해 보고 싶으면 `ollama pull qwen3:4b`(약 2.5GB)로 받은 뒤 AI 설정의 모델 이름을 `qwen3:4b`로 바꾸세요 (약 1분). 다만 4b는 경쟁상품 리뷰를 빠뜨리는 등 분석 품질이 낮습니다.

## 배포하기 (GitHub + Cloudflare Pages + Cloudflare 무료 AI)

다른 사람도 인터넷 주소로 쓸 수 있게 올리는 방법입니다. 비용은 들지 않습니다.

- **화면(웹사이트)**: Cloudflare Pages가 GitHub 저장소의 파일을 그대로 보여 줍니다. 주소: https://ai-sales-helper.pages.dev
- **AI**: `worker/worker.js`를 Cloudflare Worker로 올리면, 방문자가 API 키 없이 Cloudflare 무료 AI(`@cf/google/gemma-4-26b-a4b-it`)로 분석할 수 있습니다.
  - 무료 한도는 하루 10,000 뉴런입니다. 상품 분석 1회에 약 50뉴런, 약 20~30초가 걸려 하루 약 200회(판매 콘텐츠까지 만들면 그보다 적게) 쓸 수 있습니다 (2026-11-13 실측). 모든 방문자가 함께 나눠 씁니다.
  - 매일 한국 시간 오전 9시에 다시 채워지며, 다 쓰면 요금 없이 "오늘 사용량을 모두 썼다"는 안내만 나옵니다.
  - 상품 사진과 PDF 자료는 반영되지 않습니다 (텍스트 자료는 반영).
  - Claude API 키가 있는 사람은 AI 설정에서 Claude를 골라 계속 쓸 수 있습니다.

### 1. Cloudflare Worker 만들기
1. Cloudflare 대시보드 → **Workers & Pages** → **Create** → Worker를 만들고 이름을 정합니다 (예: `sellhelper-ai`).
2. **Edit code**에서 기본 코드를 지우고 `worker/worker.js` 내용을 붙여 넣습니다. `ALLOWED_ORIGINS`의 주소가 내 사이트 주소인지 확인한 뒤 **Deploy**합니다.
3. Worker의 **Settings → Bindings**에서 **Workers AI** 바인딩을 추가하고 변수 이름을 `AI`로 정합니다.
4. Worker 주소를 브라우저로 열어 "Worker가 동작 중입니다"가 보이면 성공입니다.

### 2. 사이트에 Worker 주소 넣기
`js/config.js`의 `WORKER_URL`에 위 Worker 주소를 넣습니다. 이 주소는 비밀이 아니라 공개되어도 괜찮습니다.
(API 키는 절대 코드나 GitHub에 넣지 마세요.)

### 3. GitHub에 올리고 Cloudflare Pages로 공개하기
1. GitHub 저장소(`ai-sales-helper`, Public)에 이 폴더를 올립니다. `backup/`, `docs/` 폴더는 `.gitignore`로 제외됩니다.
2. Cloudflare 대시보드 → **Workers & Pages** → Pages → **Connect to Git**에서 이 저장소만 선택해 연결합니다. 빌드 명령은 비우고, 출력 폴더는 `/`로 둡니다.
3. 사이트 주소: **https://ai-sales-helper.pages.dev**
4. 이후 GitHub에 올리면(`git push`) 1~2분 뒤 사이트가 자동으로 업데이트됩니다.

## 기능

- 상품 정보 입력: 판매 플랫폼(맨 위), 플랫폼별 카테고리(대분류 → 중분류), 사진(최대 3장, 선택), 상품명, 설명, 재질, 크기(가로·세로·높이 숫자 칸), 구성품(비워 두면 '단품'), 인증 정보(종류 선택 + 번호 + 공식 조회 확인), 원가, 판매가, 배송비, 포장비, 수수료, 목표 마진율. 금액 칸에는 '원', 비율 칸에는 '%' 단위가 붙어 있음
- 입력 검사: 숫자·기호만 쓴 상품명·카테고리, 너무 짧은 설명, 100원 미만 판매가, 잘못된 크기·인증번호는 분석 전에 막음. 원가 0원, 1,000원 미만 판매가, 손해 나는 가격은 '맞나요?'로 한 번 확인
- 오타 검사: **오타 검사** 버튼을 누르면 AI가 상품명·설명·재질·구성품·인증 이름의 오타와 맞춤법을 찾아 보여 줌. **고치기**를 눌러야 바뀜 (무료 AI로 약 5초)
- 분석 대기 안내: 화면을 가리지 않고 오른쪽 아래 상자에 지난 시간(보통 1~2분 기준 막대), AI가 살펴보는 내용, 3분이 넘으면 안내 문구를 보여 줌. 기다리는 동안 다른 화면을 볼 수 있고, 끝나면 상자의 **결과 보기**로 이동 (판매 콘텐츠 만들기도 같음)
- 분석 중 취소: 오른쪽 아래 상자의 **취소** 버튼으로 AI 요청을 멈춤 (입력 내용은 그대로, 저장되지 않음)
- AI 상품 분석: 주요 특징, 장단점, 강조할 장점과 근거(입력 자료와 연결), 타깃 고객층, 시장성, 차별화 요소, 위험요소와 개선 방향
- '확인 필요' 표시: 입력 자료로 확인되지 않은 내용에 노란 표시. 인증은 입력한 것만 사용
- 결과 문구 수정·복사: 각 항목의 수정·복사 버튼. 고친 내용은 저장된 분석에도 반영
- 상세페이지 만들기: 판매 콘텐츠의 상세페이지 구성안과 상품 사진(최대 3장)을 고정 서식에 배치하고, 미리보기에서 글자를 바로 고친 뒤 가로 1720px PNG로 내려받음. 색상 3종. 규격·인증 칸은 입력한 값만 사용. 사진은 저장되지 않음
- 판매 콘텐츠 만들기: 분석 결과(수정한 내용 포함)를 바탕으로 상품명 후보 3개, 검색 키워드 8~10개, 상세페이지 구성안(5개 블록), 홍보문구(인스타그램·검색광고·한 줄 카피) 초안을 만듦. '최고', '100%', '무독성' 같은 과장 표현이 있으면 경고. 검색 키워드의 실제 검색량은 확인하지 않음
- 판매 수익성 분석: 예상 순이익, 마진율, 손익분기 판매가, 목표 마진 권장가, 가격 변경(±10%, ±20%)별 비교
- AI 종합 평가: 시장성·경쟁력·수익성·차별화 가능성·판매 위험도 점수(100점 만점, 참고용 추정치)와 판매 추천 / 추가 검토 / 판매 비추천 판정
- 경쟁상품 분석: 2026-11-14에 경쟁상품 입력·자료 업로드 기능을 뺐음. 그 전에 경쟁상품을 넣어 저장한 기록에서만 결과 화면에 보임
- 분석 결과 저장: 분석할 때마다 이 브라우저에 자동 저장 (사진·업로드 자료 원본은 저장하지 않음)
- 상품 비교: 저장된 분석 중 2~5개를 골라 점수와 마진을 표·그래프로 비교
- PDF 다운로드: 결과 화면의 **PDF 다운로드** 버튼

## 계산·판정 기준

- 순이익 = 판매가 − 원가 − 배송비 − 포장비 − (판매가 × 수수료율)
- 권장 판매가 = (원가 + 배송비 + 포장비) ÷ (1 − 수수료율 − 목표 마진율), 100원 단위 올림
- 수익성 점수: 마진율 0% = 20점, 40% 이상 = 100점 (AI가 아닌 계산값)
- 시장성·경쟁력·차별화·위험도 점수: AI가 입력 정보만으로 추정
- 종합 점수 = (시장성 + 경쟁력 + 수익성 + 차별화 + (100 − 위험도)) ÷ 5
- 판정: 순이익 0원 이하, 종합 50점 미만 또는 위험도 75점 이상 → 판매 비추천 / 종합 70점 이상, 위험도 60점 미만, 마진율 15% 이상 → 판매 추천 / 그 외 → 추가 검토

AI에는 실제 시장 데이터나 경쟁상품 정보를 조회하는 기능이 없습니다. 확인되지 않은 수치나 경쟁 브랜드를 지어내지 않도록 지시되어 있으며, 모든 점수는 참고용입니다.

## 판매 플랫폼별 카테고리와 수수료 (2026-11-12 조사)

상품 기본 정보 맨 위에서 판매 플랫폼을 고르면, 그 플랫폼의 카테고리를 대분류 → 중분류로 고를 수 있고 수수료가 자동으로 들어갑니다. 수수료 칸은 직접 고칠 수 있습니다. 플랫폼을 바꾸면 카테고리가 비워지고 안내 문구가 나옵니다. **직접 입력**을 고르면 카테고리를 글자로 적고 수수료도 직접 넣습니다. 고른 '플랫폼 > 카테고리' 경로는 AI 요청문, 결과 화면, 저장 목록, PDF에 함께 표시됩니다.

| 플랫폼 | 카테고리 | 수수료 | 출처 | 상태 |
|---|---|---|---|---|
| 쿠팡 | 공식 대분류 15개 + 표에 있는 예외 중분류·소분류 | 4~10.9% (예: 생활용품 기본 7.8%, 청소/세탁/욕실용품 10.8%) | https://cloud.mkt.coupang.com/Fee-Table (표 기준일 2019.11.25) | 공식 |
| G마켓 | 공식 대분류 + 예외 중분류 | 1~15% | https://item.esmplus.com/gmarket-service-fee.html | 공식 |
| 옥션 | 공식 대분류 + 예외 중분류 | 1~15% | https://item.esmplus.com/auction-service-fee.html | 공식 |
| 11번가 | 11번가 쇼핑 화면 메뉴의 대분류 11개·중분류 | 전부 13% | 요율표는 셀러오피스 로그인 필요 | **확인 필요** |
| 네이버 스마트스토어 | 대분류 12개 (중분류 없음) | 6.63% (네이버쇼핑 유입 기준, 카테고리와 무관) | 비공식 자료 | **확인 필요** |

- 쿠팡·G마켓·옥션 표에 따로 적힌 항목만 예외 요율이고, 나머지는 '그 외'(대분류 기본 요율)를 고르면 됩니다.
- 네이버는 네이버쇼핑(검색)으로 들어온 주문 기준 6.63% 하나만 씁니다. 판매자가 만든 SNS·마케팅 링크로 들어온 주문은 실제로 더 낮지만(약 4.63%), 넉넉하게 계산하려고 높은 쪽으로 통일했습니다. 예전에 '마케팅 링크 유입'으로 저장한 분석도 그대로 열립니다.
- 별도 비용(계산에는 넣지 않고 안내만 함): 쿠팡 서비스 이용료 월 55,000원(월 매출 100만 원 이상), G마켓·옥션 선결제 배송비의 3.3%와 서버 이용료 월 55,000원(전월 판매액 500만 원 이상).
- 예전에 저장한 분석(플랫폼별 카테고리 도입 전)도 그대로 열립니다. 카테고리는 '(이전 카테고리)'로 표시되고, 예전 'G마켓·옥션'은 G마켓으로 불러옵니다. 저장했던 수수료와 계산 결과는 바뀌지 않습니다.
- 값과 출처는 `js/platforms.js` 맨 위에 적혀 있고, 그 파일에서 바꿀 수 있습니다.

## 파일 구성

- `index.html`: 화면 구조
- `styles.css`: 디자인
- `js/profit.js`: 수익성 계산과 종합 판정 규칙
- `js/platforms.js`: 판매 플랫폼별 카테고리·수수료와 출처
- `js/ai.js`: AI 호출 (Claude `claude-opus-5-5`, Qwen 테스트 모드, Cloudflare 무료 AI)
- `js/config.js`: 배포 설정 (Cloudflare Worker 주소)
- `worker/worker.js`: Cloudflare Worker 코드 (무료 AI 연결 통로)
- `js/store.js`: 분석 결과 저장 (브라우저 localStorage)
- `js/app.js`: 입력 처리, 결과 표·그래프, 저장 목록, 비교, PDF
